# Lean dependency data

James Shore’s v0.2 dataset maps the compiled proof terms for the five targets to project declarations and source lines. The union of those targets uses 804,912 project source declarations. The graph metadata is CC0. Source links point to CocoSgt’s mirror at commit `0fb9869c6e6d7b54b67de803af0e0be29d37fc22`. The author retains rights to the submitted Lean proof and the announcement. [Release](https://github.com/james-shore/rh-proof-dependencies/releases/tag/v0.2) · [Data dictionary](https://github.com/james-shore/rh-proof-dependencies/blob/v0.2/docs/dataset.md) · [Data license](https://github.com/james-shore/rh-proof-dependencies/blob/v0.2/LICENSE) · [Proof source license note](https://github.com/leanprover-community/riemann-hypothesis#license)

In the source table each edge runs from a declaration to a declaration it references. An edge can occur in a type, a proof or definition body, or both. Some generated kernel constants map to one source declaration. Some shared auxiliary lemmas remain separate constants.

`omitted` counts distinct direct project targets outside the current indexed selection. A reference in both a type and a body counts once. Mathlib, Lean core, inductive-block membership and literal dependencies have separate coverage upstream. [Project edge table](https://github.com/james-shore/rh-proof-dependencies/blob/v0.2/docs/dataset.md#decl_edges-the-project-declaration-graph-over-the-whole-environment-20372294-rows)

The browser opens on 639 declarations and can expand into the complete used source graph. All 804,912 declarations accept reviews. [Full graph, witness paths and rebuild](corpus.md)

## Build the pinned declaration selection

From the project directory, run this command with Python 3.11 or later. It downloads about 165 MB into the supplied cache and verifies the SHA-256 of each input before reading it.

```sh
python3 scripts/build-lean-index.py --cache /tmp/riemann-atlas-shore-v02
```

| Input | SHA-256 |
| --- | --- |
| `decls.csv.gz` | `af5daf53fdb72862666665eaf02a6f22b3307d5e0d175e3864d37a1ebcc9b4db` |
| `decl_edges.csv.gz` | `0e450a0120add04c917c574150a2898db6c07c87e1da9623d2eafe506ddc2025` |
| `why-parents.csv.gz` | `200328c49d1918bf67a95e98dc0873f033e207c4efcdb21a963c5a828a70a330` |

The generated `site/data/lean-index.json` holds five roots, twelve mathematical landmarks and their representative Lean declarations. The selection includes the first six levels of project declarations in the shortest-path tree, connections to the landmarks and their neighbors through depth thirteen, and every direct project reference between selected declarations reachable from the five targets. Each entry has a compiled source span.

For each node, `deps[i]` names a reference and `refKinds[i]` is `type`, `value` or `both`. `kernelDepth` is the shortest distance in the kernel-constant graph. The generator selects declarations using the distance in the source-declaration graph. The same inputs reproduce the same index bytes. [Five target declarations](https://github.com/CocoSgt/riemann-hypothesis-lean/blob/0fb9869c6e6d7b54b67de803af0e0be29d37fc22/src/Main.lean)

## Query the full database

The SQLite index contains 1,063,284 source declaration rows and 20,372,294 project reference rows, including declarations outside the five target closures. The declaration table includes 1,884 definitions generated by notation and related commands. Some shared auxiliary constants have no separate source span. [Upstream data](https://github.com/james-shore/rh-proof-dependencies/releases/tag/v0.2)

```sh
python3 scripts/lean-db.py --db /tmp/riemann-full.sqlite build --cache /tmp/riemann-atlas-shore-v02
python3 scripts/lean-db.py --db /tmp/riemann-full.sqlite show Formalism.UG.P.conv_finDosetSupp
python3 scripts/lean-db.py --db /tmp/riemann-full.sqlite show rhOfAll --direction callers --limit 10
python3 scripts/lean-db.py --db /tmp/riemann-full.sqlite search 'UpperTheory.Comparison₂.' --limit 20 --offset 20
```

Results are JSON. `deps` lists prerequisites, `callers` lists direct dependents and `inFiveTargets` records inclusion in their union. Use `--limit` and `--offset` to page through either direction. For a neighbor with `kind: "constant"`, pass `--kind constant` to the next query. `locations` lists all matching source spans.

## Add a declaration to the pinned selection

1. Find the full name, pinned source, span and `inFiveTargets` using `show`.
2. Add it to `site/data/review-targets.json` and regenerate `lean-index.json`. The generator checks the input digests, exact name and target membership. Paths that pass through auxiliary constants without source positions retain that boundary.
3. Include the target list and regenerated index in the PR. The review ID uses `lean:` followed by the full declaration name. Maintainers can reproduce a change to the opening view from these files.
